# Network Utility CLI Tool

Утилита командной строки на Python для базового анализа сети. Позволяет сканировать локальную сеть, выполнять DNS-запросы и проверять доступность узлов по ICMP (ping).

---

## 🚀 Основные возможности

1. **Сканирование локальной сети (`Local Network Scan`)**
   - Автоматически определяет подсеть роутера (проверяет популярные адреса `192.168.0.1`, `192.168.1.1`, `192.168.10.1`, `192.168.100.1`).
   - Проверяет доступность узлов в диапазоне от `.2` до `.99` с визуальным прогресс-баром.
   - Выводит древовидную схему найденных устройств и сохраняет список активных IP в файл `localnetworkscan.txt`.

2. **DNS-поиск домена (`Domain lookup`)**
   - Определяет IP-адреса, привязанные к указанному домену (через `nslookup`).
   - Выводит результаты в удобном графическом блоке и автоматически сохраняет их в файл `<домен>.txt`.

3. **Проверка доступности узлов (`Ping IP`)**
   - Поддерживает одиночную проверку задержки (ping) для введенного IP-адреса.
   - Поддерживает пакетную проверку из текстового файла (если в качестве цели указан `.txt` файл со списком IP-адресов).

4. **Сканирование портов (`IP Port Scan`)**
   - Находится в процессе разработки (заглушка для будущего функционала).

---

## 🛠 Зависимости и требования

Для запуска требуется **Python 3.7+** и следующие сторонние библиотеки:

- `ping3` — отправка ICMP-запросов (ping).
- `colorama` — цветное оформление интерфейса в консоли.
- `python-nmap` — модуль взаимодействия с Nmap.
- `nslookup` — проведение DNS-запросов.

> **Примечание:** Для корректной работы ICMP-запросов (модуль `ping3`) на операционных системах Linux и macOS могут потребоваться права суперпользователя (`sudo`).
